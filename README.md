# Weather App

A simple weather application that allows users to search for a city and retrieve real-time weather data, including temperature, humidity, and wind speed.

## Features
- Search for weather information by city name
- Displays temperature, humidity, and wind speed
- Dynamic weather icons based on current conditions
- Error handling for invalid city names

## Live Demo
You can check out the live version of this project here: [Weather App](https://project-weather-app-fa.netlify.app/)

## Purpose
This project was created for learning purposes, following a tutorial to understand how to integrate APIs and build dynamic web applications.
